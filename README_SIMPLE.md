# 🎯 APK Builder - Interfaz Ultrasiimple

**Solo 3 pasos - Eso es todo lo que necesitas**

---

## 🚀 Iniciar

```bash
chmod +x start_simple.sh
./start_simple.sh
```

Luego abre: **http://localhost:5000**

---

## 📝 Pasos

### 1️⃣ Subir Proyecto
- Haz clic en la zona de carga
- O arrastra tu proyecto ZIP

### 2️⃣ Compilar
- Presiona el botón **"Iniciar Compilación"**
- Espera a que termine

### 3️⃣ Descargar
- Presiona **"Descargar APK"**
- ¡Listo!

---

## ✅ Eso es todo

No hay opciones complicadas.
No hay configuraciones.
Solo: **Subir → Compilar → Descargar**

---

## 🛠 Requisitos

- Python 3
- Gradle (en tu proyecto)
- Android SDK

---

## ⚠️ Troubleshooting

**"Puerto ya en uso"**
```bash
./start_simple.sh 8000
# Luego abre: http://localhost:8000
```

**"Compilación falla"**
- Verifica que tu proyecto Android sea válido
- Asegúrate de tener Gradle instalado
- Revisa los logs en la interfaz
