# ⚔️ MAYORDOMO Swiss Knife v1.0\n\n> Una navaja suiza digital completa en una aplicación web para tu Android\n\n## 🎯 ¿Qué incluye?\n\n### 🌐 RED\n- Escaneo de IPs y dominios\n- Geolocalización en tiempo real\n- Información de ISP y zona horaria\n- Análisis de conectividad\n\n### ⚙️ SISTEMA\n- Información de dispositivo Android\n- Estado de RAM y storage\n- Información de pantalla\n- Monitoreo de recursos\n\n### 🔍 OSINT\n- Búsqueda de información pública\n- Análisis de correos y dominios\n- Verificación de usuarios\n- Lookups de datos públicos\n\n### 🛠️ TOOLS\n**Conversores:**\n- Base64 encode/decode\n- Hexadecimal encode/decode\n- URL encode/decode\n- JSON formatter\n\n**Generadores:**\n- UUID (v4 random)\n- Hash SHA256 simulado\n- Contraseñas fuertes (16 caracteres)\n- QR codes\n\n**Calculadora:**\n- Operaciones básicas (+, -, ×, ÷)\n- Porcentajes y potencias\n- Interfaz científica\n\n## 🚀 Cómo usar en Acode\n\n### Opción 1: Archivo único\nSi tienes Acode instalado:\n\n```bash\n1. Acode → Menu → Open folder\n2. Selecciona /home/user/termux-app\n3. Abre index.html\n4. Presiona Play (▶️) para ver la app\n```\n\n### Opción 2: Crear proyecto nuevo\n\n```bash\n1. Acode → Create new project → Web Project\n2. Copia el contenido de:\n   - index.html → main.html\n   - style.css → styles.css\n   - script.js → script.js\n   - app.js → app.js\n3. Actualiza las rutas en el HTML si es necesario\n4. Presiona Run\n```\n\n### Opción 3: Host local\n\n```bash\n# En tu PC o servidor\ncd /home/user/termux-app\npython3 -m http.server 8000\n\n# En Acode/navegador Android\n# Ve a: http://tu-ip:8000\n```\n\n## 📱 Uso en la app\n\n### Red Module\n```\n1. En `index.html`, agrega tab en nav:\n```html\n<button class=\"nav-btn\" data-module=\"nuevo\">🆕 Nuevo</button>\n```\n\n2. Agrega sección en main:\n```html\n<section id=\"nuevo-module\" class=\"module\"></section>\n```\n\n3. En `script.js`, agrega evento:\n```javascript\nif (moduleName === 'nuevo') {\n    renderNuevoModule();\n}\n```\n\n## 📊 Estructura de archivos\n\n```\n.\n├── index.html              # Estructura HTML\n├── style.css               # Estilos (responsive)\n├── script.js               # Lógica principal\n├── app.js                  # Módulos TOOLS\n├── ACODE_PROMPT.md         # Guía de Acode\n└── README_MAYORDOMO.md     # Este archivo\n```\n\n## 🐛 Debugging en Acode\n\n1.
