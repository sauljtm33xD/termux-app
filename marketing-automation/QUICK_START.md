# 🚀 QUICK START - 2 Minutos

## 💻 Para PC - Opción A (Más Fácil)

```bash
cd marketing-automation
chmod +x build-pc.sh
./build-pc.sh
```

Luego ejecuta:

**Linux/Mac:**
```bash
cd dist/pc && ./launch-pc.sh
```

**Windows:**
```bash
cd dist/pc && launch-pc.bat
```

**Acceso:** http://localhost:3000

---

## 📱 Para Android APK

```bash
cd marketing-automation
chmod +x build-apk.sh
./build-apk.sh
```

Selecciona método (1 o 2) y espera ~15-30 minutos.

**Resultado:** APK descargado

**Instalar:**
```bash
adb install marketing-automation-v1.0.0.apk
```
