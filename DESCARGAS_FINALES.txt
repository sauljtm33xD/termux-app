═════════════════════════════════════════════════════════════════════════════

Paso 1: Abre Termux en tu móvil

Paso 2: Copia y pega esta línea COMPLETA en Termux:

MÉTODO 2: DESCARGAR ZIP
═════════════════════════════════════════════════════════════════════════════

1. Descarga: termux-manager-v1.0.zip

2. Transfiere el ZIP a tu móvil (Google Drive, Email, etc.)

3. En Termux, ve a la carpeta de Descargas:
       cd ~/Downloads
       (o cd /sdcard/Download)

4. Extrae el ZIP:
       unzip termux-manager-v1.0.zip

5. Entra a la carpeta:
       cd termux-manager-app

6. Ejecuta el instalador:
       bash install-termux-manager.sh

7. Cuando termine:
       termux-manager

═══════════════════════════════════════════════════════════════════════════════

MÉTODO 3: INSTALACIÓN MANUAL (PARA EXPERTOS)
═════════════════════════════════════════════════════════════════════════════

1. Descarga el archivo "termux-manager"

2. En Termux:
       mkdir -p ~/.termux-manager
       cd ~/.termux-manager

3. Transfiere el archivo descargado a esa carpeta

4. Dale permisos:
       chmod +x termux-manager

5. Crea el enlace:
       ln -s ~/.termux-manager/termux-manager $PREFIX/bin/termux-manager

6. Ejecuta:
       termux-manager

DESPUÉS DE INSTALAR - PRIMEROS PASOS:
═════════════════════════════════════════════════════════════════════════════

1️⃣ VER EL MENÚ:
    termux-manager

2️⃣ INSTALAR LO BÁSICO:
    termux-manager install-basic
    (Instala: curl, git, python, nodejs, vim, openssh, etc.)

3️⃣ OPTIMIZAR:
    termux-manager optimize
    (Actualiza y limpia todo)

4️⃣ VER INFORMACIÓN DEL SISTEMA:
    termux-manager system-info

5️⃣ INSTALAR HERRAMIENTAS ESPECIALES:
    termux-manager install-community
    (Elige: nmap, hydra, golang, rust, php, postgresql, etc.)

SOLUCIÓN RÁPIDA DE PROBLEMAS:
═════════════════════════════════════════════════════════════════════════════

❌ "curl: not found"
→ Ejecuta: apt update && apt install curl

❌ "No hay conexión"
→ Verifica WiFi o datos móviles
→ Intenta: ping 8.8.8.8

❌ "Permiso denegado"
→ Ejecuta: chmod +x ~/.termux-manager/termux-manager

❌ "No hay espacio"
→ Ejecuta: termux-manager optimize

❌ "Error de descarga"
→ Intenta con: apt install wget
