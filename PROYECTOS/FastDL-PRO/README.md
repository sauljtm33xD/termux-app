```
FastDL-PRO/
├── src/                    (Código fuente)

```

## 🚀 Inicio Rápido

### Windows
1. Abre: `instaladores/install_fastdl_pro.bat`
2. Espera a que termine
3. ¡Listo!

### Linux/macOS
```bash
cd instaladores
bash install_fastdl_pro.sh
```

## ⚡ Características

- 16 conexiones paralelas
- 4 MB chunk size
- Descargas segmentadas
- 3-4x más rápido (34-36 MB/s)

Ver documentación completa en `/DOCS/`
