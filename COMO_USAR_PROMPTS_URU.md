# Cómo Usar los Prompts de URU en Google Studio

## Tienes 2 Prompts para Alternar

### 1️⃣ **PROMPT COMPACTO** (Técnico, Directo)
- Respuestas de 1-2 líneas
- Ideal para comandos técnicos
- Sin presentación larga
- Archivo: `URU_PROMPT_COMPACTO.md`

### 2️⃣ **PROMPT CASUAL** (Natural, Conversación)
- Habla como amigo
- Respuestas naturales en español
- Humor inteligente
- Archivo: `URU_PROMPT_CASUAL.md`

---

## Pasos para Usar en Google Studio

### Opción A: En el Navegador (Fácil)
1. Abre **https://studio.google.com** (o la URL de tu Google Studio)
2. Ve a **Settings** o **System Instructions** (donde está el prompt actual)
3. **Borra el prompt largo actual**
4. **Copia y pega COMPLETO el contenido de uno de estos archivos:**
   - `URU_PROMPT_COMPACTO.md` para modo técnico
   - `URU_PROMPT_CASUAL.md` para modo casual
5. **Guarda los cambios**
6. Prueba escribiendo algo

### Opción B: Alternar Entre Prompts
Si quieres cambiar entre compacto y casual:

1. **Guarda dos versiones en tu Google Studio:**
   - Version 1 (COMPACTO)
   - Version 2 (CASUAL)

2. **Atajos rápidos:**
   - Para cambiar a COMPACTO: "URU modo técnico" o "URU compacto"
   - Para cambiar a CASUAL: "URU casual" o "URU habla natural"

3. **O puedes tener 2 chats abiertos:**
   - Chat 1 con prompt COMPACTO
   - Chat 2 con prompt CASUAL
   - Alterna entre ellos según necesites
